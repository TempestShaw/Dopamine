# Dopamine - Your ADHD Digital Time Companion 🎯

Take control of your digital life without the mental overhead! Dopamine silently watches your computer activity and helps you understand where your time really goes.

## Why Dopamine? 🤔

- **Zero Effort Tracking**: Set it and forget it - we'll handle the rest
- **Distraction Insights**: Know what's stealing your focus
- **Privacy First**: All data stays on your device
- **ADHD-Friendly**: Real-time nudges to keep you on track

## Quick Start 🚀

1. Clone the repository with submodules:
```bash
git clone --recursive [repository-url]
```

2. Choose your platform:

### Windows
- Install .NET 8.0
- Navigate to DopamineWin directory
- Run: `dotnet run`

### macOS
- Install Xcode and Swift
- Navigate to DopamineMac directory
- Run: `swift run`

### Web Interface
- Navigate to DopamineWeb directory
- Run: `npm install && npm run dev`

## Tech Stack 🛠

### Windows (DopamineWin)
- C# with .NET 8.0
- Native Windows UI integration
- SQLite for local storage

### macOS (DopamineMac)
- Swift
- Native macOS integration
- SQLite for local storage

### Web Interface (DopamineWeb)
- React with Vite
- Modern responsive design
- Real-time data visualization
