A much smaller Windows download, the interface in Chinese, and a way to leave apps out of your numbers.

## Download

| | |
| --- | --- |
| **Dopamine-mac.zip** | macOS 12 or later, Apple silicon and Intel. Move `Dopamine.app` to Applications. This build is not notarised: on first launch choose **Open Anyway** in System Settings → Privacy & Security, then allow Accessibility access so window titles can be read. |
| **Dopamine-win.zip** | Windows 10 or later, 64-bit. Unzip and run `DopamineWin.exe`; no .NET installation needed. |

## What's new

- **Windows download is about 2 MB instead of 80 MB.** The agent is now a single native executable (Native AOT) with the dashboard built in. Data moves to `%LOCALAPPDATA%\Dopamine`; files next to the old exe are carried over on first launch.
- **简体中文 and 繁體中文.** The dashboard follows your browser language and can be switched in the header. The macOS menu bar and the Windows tray menu follow the system language.
- **Hide apps.** Open any app in the list and choose *hide this app*: its time no longer counts anywhere, including the menu bar and tray totals. Bring it back from *apps hidden · manage* under the list. Dopamine's own windows are hidden from the start.
- **Icons.** A proper macOS app icon, a menu bar icon drawn from the paint-dab logo (dimmed while paused), and the logo as the dashboard's favicon.

## Known limits

- The trackers' desktop behaviour (permission prompts, lock and sleep handling, menu bar and tray) has been checked less than the rest; please report anything odd.
- On Windows, Microsoft Store apps share one host process, so they show a letter instead of their icon.
- Community categories are built in but switched off: no server is configured, and nothing is sent.
