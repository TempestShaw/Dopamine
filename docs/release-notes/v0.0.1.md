The first release of Dopamine: a small screen-time tracker for macOS and Windows that keeps everything on your computer.

## Download

| | |
| --- | --- |
| **Dopamine-mac.zip** | macOS 12 or later, Apple silicon and Intel. Move `Dopamine.app` to Applications. This build is not notarised: on first launch choose **Open Anyway** in System Settings → Privacy & Security, then allow Accessibility access so window titles can be read. |
| **Dopamine-win.zip** | Windows 10 or later, 64-bit. Unzip and run `DopamineWin.exe`; no .NET installation needed. |

Open the dashboard from the menu bar or tray icon. It runs at `http://localhost:26535` and pairs itself.

## What's in it

- A menu bar (macOS) and tray (Windows) agent that records the app and window in front, pausing on lock, sleep and after five idle minutes.
- A dashboard with a 24-hour timeline, time per app and window with real app icons, sessions, categories, notes and a month calendar, in light and dark.
- Automatic categories (work, study, social, entertainment, other) from built-in rules and each app's own metadata, with a one-click override per app.
- Windows in front for less than five seconds are ignored.

## Known limits

- The trackers' desktop behaviour (permission prompts, lock and sleep handling, menu bar and tray) has been checked less than the rest; please report anything odd.
- On Windows, Microsoft Store apps share one host process, so they show a letter instead of their icon.
- Community categories are built in but switched off: no server is configured, and nothing is sent.
