Fix the macOS download package so its app signature survives DMG creation.

- The disk image no longer adds a Finder extension-hiding attribute to the signed app. That attribute made strict signature verification fail in the 0.0.7 DMG, even though the app passed verification before packaging.
- Packaging now mounts the final DMG read-only and verifies the app inside it before reporting success.
- No changes to tracking, stored activity, or dashboard behavior. Windows packages carry the same version for the shared release.

This fixes package integrity; it does not add Apple notarization. macOS builds remain an early, non-notarized release. Review the installation instructions before opening the app.

Download `Dopamine-mac.dmg` for macOS 12+ or `Dopamine-win-Setup.exe` / `Dopamine-win.zip` for Windows 10+.
