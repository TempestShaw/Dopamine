The dashboard in its own window, a welcome guide on macOS, and smaller updates.

- **Dashboard window:** the dashboard opens in its own desktop window instead of the browser, with frosted glass on macOS. While it's open, Dopamine shows in the Dock or taskbar like any other app.
- **Welcome guide on macOS:** the first launch walks through what Dopamine does and the Accessibility permission it needs for window titles. It notices as soon as you switch Dopamine on, and comes back at that step if setup is interrupted or access is lost. Reopen it from the **?** in the menu bar.
- **Smaller updates:** updates from the previous version download only what changed, on both macOS and Windows. Anyone further behind still gets the full package. The downloads themselves are smaller too.
- **Safer local dashboard:** only pages on this computer can talk to Dopamine's local API. Websites open in your browser can no longer reach it, even to see that Dopamine is installed.

macOS builds are still not notarized: on first launch choose **Open Anyway** in System Settings → Privacy & Security.

Download `Dopamine-mac.dmg` for macOS 12+ or `Dopamine-win-Setup.exe` / `Dopamine-win.zip` for Windows 10+. Existing v0.0.5 and v0.0.6 installs update themselves.
